✈️ Cấu Hình Telegram Bot (Khách Chat Cho Tiệm)

📖 Xem Hướng Dẫn Lấy Bot Token & Chat ID
  1. Mở Telegram, gõ tìm @BotFather, bấm Start.
  2. Gõ lệnh /newbot, đặt tên và username bot (kết thúc bằng _bot).
  3. Copy đoạn mã API Token dán vào ô Bot Token ở trên.
  4. Lấy Chat ID: Chat với bot @userinfobot để lấy ID của bạn (ví dụ 123456789). Hoặc thêm bot vào Group của tiệm để lấy ID nhóm (thường có dấu -100...).
  5. Nhập vào các ô trên và bấm "Gửi Thử Tin Nhắn Test" để xác nhận!
